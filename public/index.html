Version 2.9.0 - Basic multiclass support


Chamges:
  • Added New "Class" column displaying the class of the car.
  • Position : If the race is multiclass, and the driver is not in the leading class, then the position within the class is show, with the overall position in brackets.
Limitations :
  • Best Lap/Sector times are, for now, still overall. Making them per-class will require extensive work.
  • Assetto Corsa: AC has no multiclass concept in telemetry. The "Class" column will not be populated, and overall position will be shown at all times.
  • Automobilista: AMS way of reporting classes is weird. Reported class is in reality the manufacturer/team. Because of this the position within class has no real value. So, while this information is shown, the position will always, on purpose, display the overall position.
  • PCars 1: PCars 1 does not report car name, but only class name. This was previously shown in car name column. It is now moved to the correct column, but car name is not filled.
